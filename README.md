# NOIR & CREAM — เว็บร้านเสื้อผ้ามินิมอล (ธีมครีม ขาว ดำ)

ร้านเสื้อผ้าออนไลน์ คุมโทนสไตล์ Minimalist: ครีม (`#FAF7F2`), ขาว (`#FFFFFF`), ดำ (`#141414`)
จำหน่ายเฉพาะ 4 หมวดหมู่หลัก:
1. **เสื้อยืด** (T-Shirts)
2. **เสื้อโปโล** (Polo Shirts)
3. **เสื้อแขนยาว** (Long Sleeve Shirts)
4. **กางเกง** (Pants & Trousers)

---

## วิธีเริ่มต้นใช้งาน (ต้องใช้ Node.js 22.13 ขึ้นไป)

```bash
npm install
npm run seed      # เตรียมระบบ แอดมิน คูปอง และข้อมูลร้าน (สต็อกเริ่มต้นว่าง พร้อมให้เพิ่มสินค้าเอง)
npm start         # เปิดเซิร์ฟเวอร์
```
เปิดบราวเซอร์ที่: **http://localhost:3000**

*(หากต้องการใส่สินค้าตัวอย่าง 4 หมวดหมู่อัตโนมัติ สามารถรัน: `node seed.js --samples`)*

## ฟีเจอร์สำคัญสำหรับร้านเสื้อผ้าที่เพิ่มเข้ามา

1. **จำกัด 4 หมวดหมู่เฉพาะเจาะจง**:
   - เสื้อยืด, เสื้อโปโล, เสื้อแขนยาว, กางเกง (มี Vector Silhouette รูปทรงเฉพาะแต่ละประเภท และรองรับรูปภาพ URL)
2. **ตารางเทียบไซส์มาตรฐาน (Size Guide)**:
   - ตารางขนาด (อก, ยาว, ไหล่, เอว, สะโพก, ปลายขา) ครบทั้ง 4 หมวดหมู่
   - ปุ่มเปิดดูตารางไซส์แบบ Popup บนหน้าสินค้าทุกชิ้น
   - หน้าคู่มือเทียบไซส์และวิธีการวัดสัดส่วนร่างกาย (`#/size-guide`)
3. **ระบบจัดการสินค้า & สต็อกด่วนสำหรับแอดมิน**:
   - เพิ่มสินค้าพร้อมสร้างไซส์ (S, M, L, XL, 2XL หรือ 28-36) และสต็อกพร้อมกันในคลิกเดียว
   - ปุ่มลบสินค้าออกจากร้าน
   - ปุ่มล้างสต็อกทั้งหมดเพื่อเตรียมสต็อกใหม่
4. **ข้อมูลและนโยบายร้านค้า (Trust & Service)**:
   - นโยบายเปลี่ยนไซส์สินค้าภายใน 7 วัน
   - ข้อมูลการจัดส่งและเงื่อนไขส่งฟรีเมื่อซื้อครบ ฿1,000
   - คำแนะนำการดูแลรักษาเนื้อผ้า (Fabric Care Guide)
   - คำถามที่พบบ่อย (FAQ Accordion)
   - ช่องทางการติดต่อร้าน (LINE OA, เบอร์โทร, อีเมล)
5. **ระบบ E-Commerce ครบวงจร**:
   - ตะกร้าสินค้า, ระบบสั่งซื้อ, บันทึกที่อยู่จัดส่งได้หลายที่อยู่
   - ระบบคูปองส่วนลด, ระบบตัดสต็อกอัตโนมัติ, ระบบติดตามพัสดุ
   - รายการโปรด (Wishlist) และรีวิวเฉพาะผู้ซื้อจริง
